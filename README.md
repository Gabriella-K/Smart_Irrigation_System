# Smart Irrigation System 

A smart irrigation recommendation system that helps farmers make better watering decisions using environmental and farm data.

## Features

- AI-powered irrigation recommendations
- Soil moisture analysis
- Weather and environmental monitoring
- Farmer dashboard
- Prediction analytics
- Authentication system (Login/Signup)
- Responsive modern UI

## Technologies Used

### Frontend
- React.js
- Vite
- Lucide React
- CSS / Inline Styling

### Backend
- Python
- Flask
- Machine Learning Model
